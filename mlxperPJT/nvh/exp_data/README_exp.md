# exp_data — e10 실측 오버레이 인터페이스 (플레이스홀더)

**현재 e10 NVH 실측 데이터는 없다** (레포에 EMF 측정만 존재, 진동/소음 없음).
측정이 확보되면 이 폴더에 CSV 를 넣는 것만으로 `e10_paper_figs.py` 의
Campbell 선도(fig06)에 자동 오버레이된다(별표 마커).

## CSV 스키마 — 차수추출 레벨(order-tracked)

파일명 자유(`*.csv`), 헤더 필수:

```csv
rpm,k,freq_Hz,Lw_dB
5850,6,2340,71.2
8900,6,3560,78.9
11950,6,4780,84.1
15000,6,6000,88.5
```

| 열 | 의미 |
|---|---|
| `rpm` | 운전점 회전수 |
| `k` | 온도차수(× f_elec). 미상이면 freq_Hz/(rpm/15) 로 환산 |
| `freq_Hz` | 차수 주파수 |
| `Lw_dB` | 음향파워레벨(또는 대용지표 — 축을 명시할 것) |

주의: 시뮬레이션 ERP 는 σ_rad=1 상한이므로 절대 dB 비교 시 방사효율 보정 필요.
1차 검증은 **차수별 상대 서열·rpm 경향**으로 할 것(Chauvicourt 의 검증 방식).

## 확장(예정 스키마)
- `fft_<rpm>.csv` : `freq_Hz,level` 정상상태 스펙트럼 → fig05 오버레이용.
- 가속도계 위치 메타(`position.md`): 시뮬레이션 추출점(OD 미드스팬)과 정합 확인.
