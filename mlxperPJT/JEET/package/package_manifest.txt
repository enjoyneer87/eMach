# package_manifest.txt — source -> destination map for JEET-repro
#
# Read by make_package.py (same directory).  One entry per line:
#     @ROOT/relative/path -> package/relative/path [flag,flag]
# A destination ending in '/' is a directory; the file keeps its basename.
# A source may contain glob characters (then the destination must be a
# directory).  __pycache__ and *.pyc never match.
#
# Roots: @TOOLS @JEET @E10 @PKG (worktree defaults) and @EMACH_E10
# (no default — pass --root EMACH_E10=<path>).
# Flags: allow-abs   skip the private-path leak scan (Map_Summary JSONs
#                    carry a diagnostic backup_dir field)
#        no-outputs  insist the notebook ships without outputs
#        zenodo-sha  the source must equal the Zenodo-deposited file
#                    (verified against --zenodo-manifest)
