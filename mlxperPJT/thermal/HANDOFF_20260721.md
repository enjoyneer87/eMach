## 1. 목표

JMAG **JAC279** *"Thermal Analysis Accounting for Cooling of the IPM Motor"* 의
**3D 열 FEM + 열등가회로 하이브리드** 를 Ansys **PyMAPDL** 로 재현한다.
능동부(코어·자석·코일·샤프트)는 3D FEM, 냉각계(워터재킷·ATF·하우징)는 lumped 회로.

| JMAG | MAPDL |
|---|---|
| 3D 솔리드 열 FEM | `SOLID87` (10절점 사면체) |
| Heat Transfer Boundary (회로 참조) | `SURF152` + extra node (`KEYOPT(5)=1`) |
| Thermal Resistor | `COMBIN14`, `KEYOPT(2)=8` |
| Heat Capacity | `MASS71`, `KEYOPT(3)=1` |
| Fixed Temperature | `D, TEMP` |

## 3. 핵심 성과 — MAPDL ↔ Fluent 교차검증 통과

| | MAPDL(워터재킷) | Fluent CFD |
|---|---|---|
| 코일, 저부하 | 88.3°C | 88.3°C |
| 코일, 고부하(250A) | 119.2°C | 118.2°C |

**코일 1°C 이내 일치** — MAPDL 하이브리드 방식이 CFD 대비 정량 검증됐다.

**알려진 한계(버그 아님):** 로터·자석은 MAPDL이 13~20°C 더 높다. 에어갭을
순수 전도(0.75mm)로 모델링해 **회전에 의한 유동 강화가 빠져** 있기 때문. 문서화됨.

## 4. 재발견 비용이 큰 함정들

**MAPDL**
- `SURF152`는 `KEYOPT(8)=2` 를 **반드시** 줘야 대류가 먹는다. 기본값은 조용히 무시.
  (큐브 테스트로 검증: extra node = 해석해 40.00°C)
- `ESURF` 는 현재 REAL 을 SURF152에 묶어버려 *"Real constant referenced by types 3 and 2"*
  → ESURF 전에 전용 `mapdl.r(1)` / `mapdl.real(1)` 를 잡을 것.
- **이방성 코일**: `MP,KZZ=250` (축방향/구리) / `KXX=KYY=2.5` (횡방향/절연).
  슬롯 도선이 global-z 라 `ESYS` 불필요.
- **코일↔코어 결합은 `CONTA174`가 실패**한다 (CAD 라이너 갭 0.85~1.4mm).
  → `SURF152` 정션 노드 (각도 16 × z 4 bin, 2×TCC).
- 코일 엔드는 FEM에서 절단, 손실은 `CEND` 노드에 `mapdl.f` HEAT 로 주입.
  엔드 손실 = 슬롯 × V_end/V_slot = **0.449**.
- 곡면 중간절점 sagitta 허용오차: `1.6*ESIZE²/(8R)`

**메시 / 지오메트리**
- SATIN 은 설치 결함으로 고장 → **STEP→gmsh(OCC)→CDB** 경로 사용
  (`importShapes` → `fragment` 로 conformal → `setPeriodic` → tet10 → ×8 회전 패턴 → NBLOCK/EBLOCK)
- 메시 단위가 **미터**다. 긴 샤프트가 돌출해 GIF가 십자모양이 되던 문제 → `z_trim=0.045`

**Maxwell / AEDT**
- Maxwell 3D 가 *"Classic Parallel Recovery"* 베타 옵션(`CPRIsEnabled`)에 막혔다.
  프로그램적 우회 전부 실패 → **사용자가 GUI에서 해제**해야 풀린다.
- Prius Maxwell **19R2 → v261 마이그레이션은 pyaedt 로 실패**
  (`__init__() should return None, not 'bool'`) → 사용자가 24R2로 재저장해서 해결.
- **부품별 철손 추출은 3회 실패**했다 (`CoreLoss(obj)` 미지원, `EnterVol`/`EnterSurf` 가 nan).
  → 스테이터/로터 **90/10 추정**으로 되돌림. 한계로 문서화됨.

**시각화 (pyvista)**
- 볼륨 clip 은 VTK 를 죽인다 → **외피 반쪽 clip + 단면 slice 조합**
- `extract_cells` 를 이중으로 걸면 `vtkOriginalPointIds` 가 깨져 온도가 전부 최댓값이 된다
  → 원본 grid 인덱스를 `point_data` 로 실어 보존할 것.
- 축방향(x=0) 절단은 **코일 막대가 카메라를 가려** 코어가 안 보인다 → z=0 정단면 슬라이스 사용.
- viz 스크립트는 10분 foreground 타임아웃 → `Start-Process` 로 detach 실행.

**툴 가용성**
- **Discovery: 자동화 불가.** `ansys.discovery` / `ansys.geometry` 미설치, CFD는 GUI 전용.
- **Icepak: 자동화 가능** (pyaedt `Icepak` 클래스).
- pyfluent 0.40.2 는 `.cas.h5`/`.dat.h5` 를 읽는다. h5py 로 `SV_T` + cell zone range 직접
  읽으면 **Fluent 라이선스 없이도** 온도 추출 가능.
