## 2. e10 = FreeFlow 모터 (핵심 정체)
FreeFlow(GPU SPH 오일냉각) 프로젝트의 모터 = **e10**(JEET AC손실 논문 모터).
OD 198 / bore 142.5 / 스택 150mm / 48슬롯 8극 **더블-V IPM**. 운전점 16000rpm/460A RMS.
- 손실(실측 운전점 + Prius추정 분포): 구리3350 / 고정자철585 / 로터철65 / 자석24 W.
  → `mlxperPJT/thermal/freeflow/data/e10_losses.json`. (Motor-CAD 헤드리스가 injected
  loss를 0 반환 → Prius 추정 사용. 파라미터명은 `ActiveXParametersMotorCADv261.txt` 참조.)

## 3. e10 메시 v2 (자석·샤프트 복원 — 재발견 비용 큼)
1차 메시는 FreeFlow `Rotating.stl`이 자석포켓 non-manifold라 **로터를 단순 실린더**로
대체 → 자석/샤프트/로터적층 없었음. **v2에서 Maxwell 2D로 재구축**:
- `freeflow/scripts/02c_maxwell_geom_extract.py`: e10 Maxwell 2D(45°섹터, 8극)에서
  로터적층·**더블V 자석4/폴**·샤프트 단면 폴리곤 추출. (Maxwell 2D 좌표계 = STL과 일치, OD99mm.)
- `freeflow/scripts/03b_rotor_from_maxwell.py`: gmsh OCC로 샤프트+로터+자석(×8회전=**32자석**)
  fragment(컨포멀)→tet10, **엔드턴 포함 스테이터+권선 STL메시(mat1/3)와 병합**.
  → **`ff_e10_mesh_v2.cdb`** (⚠️ 이 머신 로컬: `D:\KDH\simVary\Ansys_Thermal\`, 260MB, git無).
  1,113,924절점 / 737,265 tet10. 재료 **1 stator·2 magnet·3 winding·4 shaft·5 rotor**.
- ⚠️ **CDB EBLOCK 함정**: tet10(10노드)은 `(19i10)`에서 **11헤더+8노드 / 나머지2노드 줄바꿈**
  필수. 한 줄에 다 쓰면 노드는 로드되나 **요소 0개**(무증상). `03b` writer 참조.

## 4. JAC279 하이브리드 MAPDL 열해석 (e10 오일냉각)
`freeflow/scripts/04_mapdl_thermal.py`: 3D FEM + **오일냉각 열등가회로**
(OIL 공급70°C → JACKET 스파이럴자켓 + SPRAY 엔드턴스프레이 + GAP_S/R 공극 + SHF 샤프트;
MASS71/COMBIN14/SURF152). 과도 900s.
- **결과**: winding 152.2 / stator 126.0 / magnet 86.9 / rotor 86.9 / shaft 84.9 °C.
  회로: JACKET 84.4 / SPRAY 91.9 / GAP_S 122.3 °C. → `data/ff_mapdl_hybrid_temps.json`.
- 시각화: `freeflow/scripts/10_mapdl_dashboard_viz.py` (thermal_viz 재사용 + FreeFlow
  냉각회로빌더) → `viz/mapdl/transient_dashboard.gif` 등. **산출물은 gdrive**.
- ⚠️ **stale MAPDL 재연결 함정**: 실패한 이전 run 인스턴스에 붙으면 깨진 상태(요소0) 그대로
  → 매 솔브전 ANSYS 프로세스 완전종료 + 새 run_location.

## 6. FreeFlow 온도장 활성화 (1-way 커플드) — 일부 이 머신 로컬
`freeflow/scripts/11~14_*.py`: FreeFlow Python API(`FreeFlow.exe --headless --script`)로
열모델 ON + MAPDL 벽온도 주입 + 오일(ATF) 흡열.
- **벽 매핑**: Stator→84.4(JACKET) / Winding→91.9(SPRAY) / Rotating→80 / Housing→76 °C.
- ⚠️ **근본원인**: Fluid Inlet(주입 오일) 온도가 0°C였음 → `SetTemperature(70)`. 벽만
  데워도 유입오일 0°C면 벌크 안 데워짐(이거 못 찾으면 온도 0K로 남음).
- ⚠️ **Rocky 결과셋 all-or-nothing**: 물리설정(벽BC·열물성·InletT) 바꾸면 기존 결과 전체
  무효화 → resume 불가, `DeleteResults()` 후 t=0 재계산. **원본 `Project.freeflow`(유동전용
  8s) 보존**, 열해석은 **`Project_thermal.freeflow`** (⚠️ 이 머신 로컬:
  `D:\KDH\simVary\simFreeFlow\20251226\FreeFlow\FreeFlowProject\`).
- 검증(1.63s): 오일 70→평균70.8/최대72.17°C 단조승온 → `data/ff_coupled_validation.json`,
  `viz/mapdl/ff_thermal_oil_*.png/gif`.
- 🔴 **진행중(이 머신 GPU)**: **전체 8초 정식 솔브**가 백그라운드 실행중(resume, ~3-4h,
  현재 ~54%). 스크립트 `scratchpad/ff_thermal_full8s.py`(로그 `ff_thermal_full8s.txt`),
  45분→4h 상한. **다른 로컬에선 이 프로세스 안 보임**; 완료되면 이 세션이 8초 최종
  온도장 재생성·gdrive·커밋 예정. 미완이면 `Project_thermal.freeflow` 결과에서
  `13/14_*.py`로 재생성 가능.
- ★ **CHT 결론**: FreeFlow 단독 CHT 불가(벽=표면삼각망/체적없음, 열경계 3종뿐 손실주입불가).
  2-way CHT는 **FreeFlow↔System Coupling↔MAPDL**(고체는 외부). 우리 1-way는 그 단방향.
