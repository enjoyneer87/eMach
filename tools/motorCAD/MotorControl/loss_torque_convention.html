손실의 토크 귀속 규약

어떤 손실이 제동토크이고 어떤 손실이 입력측인가 — 전력 평형으로 가르기
PC2 · 2026-09-17 · e10Turn6 헤어핀 IPM 실측 기준
PC1 · 2026-09-23 보강 — Motor-CAD E-Magnetic·Lab과 구동 모델이 실제로 어떻게 처리하는지(4절, 4.1–4.3), 16 krpm 운전점 수치(5절)

한 줄 요약. 판별 기준은 손실이 어디서 소산되느냐가 아니라 그 에너지가 공극을 건너오느냐입니다. 교류 동손의 주된 부분(자기 전류의 슬롯 누설이 만드는 근접손)은 공극을 지나지 않으므로 제동토크가 아닙니다. 무부하에서 회전자 자속이 만드는 부분만 제동토크입니다.

1. 왜 문제가 되는가

전류맵을 만들 때 쇄교자속 맵에서 얻는 토크는 보존장의 결합 토크입니다.

Tem = (3/2) · p · (λd iq − λq id)

이 값에는 손실이 들어 있지 않습니다. 다이나모 토크미터가 읽는 축 토크는 이보다 작습니다. 그 차이를 어떤 손실로 채울 것인가가 규약 문제이고, 구현마다 다릅니다. 같은 손실을 토크에서 빼면 전류맵이 바깥으로 밀리고, 전류로 더하면 전압 여유와 동손만 늘어납니다. 둘을 같이 하면 이중 계상이 됩니다.

주의할 것은 이것이 효율 계산의 문제가 아니라는 점입니다. 효율은 어느 규약을 쓰든 손실 총합이 같으면 같습니다. 어긋나는 것은 전류맵입니다. 같은 축 토크를 요구했을 때 나오는 전류쌍이 달라집니다.

2. 전력 평형

먼저 오해를 걷어냅니다. 전력 평형 P_in = P_shaft + ΣP_loss 는 모든 손실에 예외 없이 성립합니다. 동손이든 철손이든 축 출력을 깎습니다. 아래에서 가르는 것은 이 식이 아니라, 전류를 정했을 때 축 토크가 얼마인가 라는 다른 질문입니다.

쇄교자속 맵이 주는 토크는 보존장에서 나온 값이라 공극을 지나는 전력에 대응합니다. 그래서 위의 평형식이 공극을 경계로 두 단으로 쪼개집니다.

Pin − (단자에서 먹는 손실) = Pgap = Tem · ωmech
Pgap − (공극을 건너는 손실) = Pshaft = Tshaft · ωmech

두 식을 더하면 원래의 P_in = P_shaft + ΣP_loss 가 그대로 나옵니다. 모순이 없습니다. 차이는 어느 식에 들어가느냐입니다. 고정자 동손은 첫째 식에만 있으므로 같은 전류에서 Tem 을 바꾸지 않습니다. 전류가 같으면 토크도 같고, 다만 그 전류를 밀어 넣는 데 입력 전력과 전압이 더 듭니다. 회전자 손실은 둘째 식에 있으므로 같은 전류에서 축 토크를 실제로 깎습니다.

숫자 예

16 krpm (ωmech = 1675.5 rad/s), 어떤 전류에서 맵 토크가 100 N·m 인 경우입니다.

항목값어느 식
Pgap = 100 × 1675.5167.6 kW경계
고정자 동손 (직류 + 교류)40.0 kW첫째 — 토크 불변
회전자 철손 + 자석손 + 기계손3.0 kW둘째 — 토크 감소

검산하면 207.6 = 164.6 + 40.0 + 3.0 으로 평형이 맞습니다. 동손 40 kW 는 분명히 효율을 깎았지만, 토크가 100 에서 98.2 로 줄어든 것은 회전자 손실 3 kW 때문입니다.

용어. 이 문서에서 입력측은 "공짜"라는 뜻이 아닙니다. 같은 전류로 얻는 토크를 바꾸지 않고, 같은 토크를 얻는 데 드는 입력만 키우는 손실을 가리킵니다. 제동은 같은 전류로 얻는 토크 자체를 깎는 손실입니다.

흐름도

공극을 경계면으로 두고 전력이 어느 방향으로 흐르는지만 따지면 규칙이 하나로 정리됩니다.

판별 규칙

에너지가 공극을 건너면 → 제동토크
에너지가 공극을 건너지 않으면 → 입력측 손실

소산되는 위치가 아니라 공급원이 기준입니다. 고정자 권선에서 나는 손실이라도 회전자 자석 자속이 일을 해서 생긴 것이면 제동토크입니다. 무부하로 회전자만 돌렸을 때 드래그 토크가 존재하는 이유가 이것입니다.

4.2 교류 동손 계산 방식 — Hybrid와 FullFEA

  • Hybrid(ProximityLossModel = 1)는 정자장 FEA의 슬롯 자속밀도로 도체 와전류손을 후처리합니다. 도체 전류가 장에 반작용하지 않으므로 FEA 토크·쇄교자속은 바뀌지 않고, 손실은 입력 전력에만 더해집니다. 즉 이 규약의 "입력측" 처리와 같습니다. 16 krpm 20 N·m점은 2866 W, 무부하는 2.4 W입니다.
  • FullFEA(= 3)는 과도 FEA에서 도체를 실제 전도체로 풉니다. 와전류 반작용이 장과 토크에 들어갑니다. 같은 20 N·m점에서 평균 토크가 21.82에서 21.50 N·m로 0.32 N·m 낮고(541 W 상당), 교류 동손은 2567 W, 무부하 도체 와전류손은 6.6 W입니다. 토크 감소분이 교류 동손의 약 21 %라는 것은 "부하분은 입력측"이라는 가정과 다를 수 있습니다. 다만 TorqueNumberCycles = 1의 1주기 평균에 기동 과도가 섞여 있어 아직 분리하지 못했습니다(2주기 이상으로 재확인할 과제).
  • Lab의 교류손 맵(CalcTypeCuLoss_MotorLAB = 3, ACLossMethod_Lab = 0 = Hybrid)은 빌드 점의 Hybrid 값을 운전점에 보간합니다. 입력측으로 들어갑니다.
  • 무부하 성분(6절 가.): 16 krpm, 전류 0에서 교류 동손은 Hybrid 2.4 W, FullFEA 6.6 W로 무시할 수준입니다. 제동으로 넣어야 할 무부하 성분은 사실상 무부하 고정자 철손(1.86 kW)뿐입니다.

4.3 구동 시뮬레이션에 넣는 방법

시간영역 구동 모델(스크립트·Simscape)과 정상상태 운전점 계산기(qs_opsolver.py)는 이 규약을 이렇게 구현합니다.

토크표: Tshaft(id, iq) = Tem − ( Pmech + Pfe,rotor + Pmagnet + Pfe,stator,NL + Pcu,ac,NL ) / ωmech
전압: v = ( Rdc + Rac,eff ) i + jωeψ(i), Rac,eff = ( Pcu,ac − Pcu,ac,NL ) / ( 1.5 |i|2 ) (첨두 기준)

16 krpm 기준표 운전점에서 Rac,eff ≈ 0.050 Ω로, 직류 저항 0.0786 Ω의 약 63 %입니다. 이 몫이 필요 전압을 0.9–2.8 % 올립니다(5절). 부하분 고정자 철손(85–613 W)은 등가 전류로 넣을 수 있지만 전압 영향이 작아 생략했습니다.

시간영역에서 본 효과 (Simscape 단계 2d, 09-23 밤). 같은 모델에서 전동기 표만 기존(Lab 정의 축 토크, Rdc)에서 이 규약(축 토크 식 + Rac,eff)으로 바꾸면, 여유 없이 한계선에 붙인 기준표(MCB)의 20 N·m가 −3.1 %에서 −9.3 %로 나빠지고 전압 포화가 0 %에서 100 %가 됩니다. 5 % 여유 기준표(MBC 95)에서는 −1.4 %에서 −1.8 %로 여유가 흡수합니다. 정상상태 계산기의 QS 기준표는 Rac를 한계식에 넣어 만들므로 이 몫이 처음부터 여유 계산에 들어갑니다. 같은 실험에서 회전자 위치별 FEA 맵(슬롯 고조파)의 영향은 이보다 훨씬 컸습니다(5 % 여유 표 20 N·m −60 %). 자세한 내용은 진각 벽 보고서 4.9절에 있습니다.

6. 다른 로컬에서 할 검증

가. 무부하 성분 분리 (Motor-CAD 필요) — 09-23 PC1 완료

전류 0, 16 krpm, ProximityLossModel = 3으로 한 점 실행합니다. 얻은 무부하 도체 와전류손과 고정자 철손을 위 축 토크 식의 제동 항에 넣습니다. 소요는 한 점 약 10분입니다. 결과: 도체 와전류손 6.6 W(FullFEA, 약 3.5분), 고정자 철손 1855.5 W(adj). 4.2절 참고.

나. eMach 전류맵 코드 점검 (MATLAB)

findOptimalCurrentsWithConstraints.m의 목적함수가 최적화 변수를 쓰지 않습니다.

function totalCurrent = compMTPA(obj, Im_rms)
    ...
    totalCurrent = sqrt(obj.lastIRMS(1).^2 + obj.lastIRMS(2).^2);
    % obj = obj.updateElecLossData(Im_rms);   <- 주석 처리됨
end

인자 Im_rms가 본문에서 쓰이지 않고 저장된 상태만 읽습니다. 게다가 fmincon에 넘기는 익명 함수가 생성 시점의 객체를 값으로 붙잡으므로, 제약 함수가 객체를 갱신해도 목적함수에는 반영되지 않습니다. 생성자에서 lastIRMS = [0, 0]이므로 목적함수가 상수가 되고, fmincon은 최소화할 것이 없어 실질적으로 실행 가능성만 풉니다. 결과는 초기 추정점 근처의 아무 실현 가능점이며 MTPA도 손실 최소도 아닙니다.

수정은 인자만으로 계산하도록 바꾸면 됩니다.

function J = compMTPA(obj, Im_rms)
    o = obj.updateElecLossData(Im_rms);
    J = sqrt(o.lastIRMS(1)^2 + o.lastIRMS(2)^2);
end

손실 최소 기준으로 가려면 같은 자리에서 J를 총손실로 바꿉니다. 구조 변경은 필요 없습니다.

다. 회귀 케이스

MainComp_MTPA.m에 이미 케이스가 있습니다.

[idm_rms_opt, iqm_rms_opt, id_rms, iq_rms, eeclutdq_out] = ...
    findOptimalCurrentsWithConstraints(438.2, 720*0.97, EECLUTdqArray(4), MCADLinkTable);

15000 rpm, 438.2 N·m, 전압 한계 698.4 V입니다. 수정 전후로 같은 케이스를 돌려 dq2pkBeta로 얻는 진각이 얼마나 움직이는지 보면 목적함수 문제의 실제 영향이 나옵니다. 움직임이 없으면 초기 추정이 이미 최적이었다는 뜻이고, 크게 움직이면 지금까지의 전류맵을 다시 만들어야 합니다.

라. 이중 계상 확인

EECLUTdq.evaluateMotorConstraints가 TorqueElecLossWODCLoss를 토크에서 빼는 동시에 calcCurrentElecLoss가 만든 idsRMS, iqsRMS를 전류에 더합니다. 두 경로가 같은 손실을 가리키는지 확인이 필요합니다. 같은 손실이면 3절 표대로 제동분과 입력측분을 먼저 나눈 뒤 각각 한 경로에만 넣어야 합니다.

7. 요약

  • 전력 평형은 모든 손실에 성립한다. 가르는 기준은 평형식이 아니라 "같은 전류에서 토크를 바꾸는가"다.
  • 제동이냐 아니냐는 소산 위치가 아니라 에너지가 공극을 건너오느냐로 가른다.
  • 교류 동손의 주된 부분은 입력측이다. 무부하 성분만 제동이다.
  • 고정자 철손도 같은 방식으로 갈린다. 무부하 드래그 토크가 그 증거다.
  • 같은 손실을 토크와 전류 양쪽에 넣으면 이중 계상이다.
  • SyR-e 두 파일과 eMach 전류맵 코드의 규약이 서로 다르다. 하나로 고정해야 한다.
  • Motor-CAD도 모듈마다 다르다. E-Magnetic은 자석손을 입력측으로, Lab은 제동으로 둔다. 둘 다 고정자 철손 전체를 제동으로 둔다(4.1).
  • Hybrid 교류 동손은 장에 반작용하지 않아 FEA 토크를 바꾸지 않는다. 그 자체로 "입력측" 처리다. FullFEA는 같은 점에서 토크를 0.32 N·m 낮췄는데, 기동 과도와의 분리가 남아 있다(4.2).
  • 16 krpm 약자속에서 규약은 축 토크를 거의 바꾸지 않는다. 대신 입력측 교류 동손이 필요 전압을 1–3 % 올린다. 여유 없는 기준표에는 이 몫이 결정적이다.
