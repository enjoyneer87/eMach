# PC2 후속: 손실 가지·단위·전력수지 정비

2026-09-25, PC1. 앞선 수치 최적화 수정 `d671963`의 후속이다.
새 FEA나 실측을 수행하지 않았다. 기존 P1/P2 결과와 논문 정본을 대체하지 않는다.

## 명시한 계산 계약

맵의 입력은 **자화 dq 전류의 첨두**, 공개 최적화 입출력은 RMS,
전압 한계는 **상전압 첨두**, `nTarget`은 **기계 rpm**, `omegaE`는 전기 rad/s다.
생성자에서 극수에 따른 기계/전기 속도 일치를 검사한다.

```
e_pk = omegaE * [-lambdaQ, lambdaD]
i_loss_pk = (2/3) * InputW * e_pk / dot(e_pk,e_pk)
I_total_rms = I_magnetizing_rms + i_loss_pk/sqrt(2)
V_pk = Rdc * I_total_pk + e_pk
T_shaft = (3/2)*(poles/2)*(lambdaD*iq_m_pk-lambdaQ*id_m_pk) - DragW/omegaM
P_terminal = omegaM*T_shaft + 3*Rdc*|I_total_rms|^2 + InputW + DragW
```

`InputW`는 유기전압에 병렬인 등가 shunt 가지의 손실이다. `DragW`는 독립적으로
귀속한 축 제동 손실이다. 두 값은 호출자가 명시하며, 전력수지가 성립하는 것만으로
실제 물리적 귀속을 선택하지 않는다. 총전류 기준 토크로 표현할 경우 `InputW/omegaM`
상쇄 항이 필요하며 자화 전류 기준과 동일해지는 것을 별도로 검사했다.
Park/dq 전력 규약 참고: [MathWorks PMSM](https://www.mathworks.com/help/simscape-electrical/ref/pmsm.html).

- 손실 0은 전류 0, 저항 Inf인 열린 가지다. 자속축 경계에서도 유효하다.
- 유기전압 0에 양의 shunt 손실 또는 정지점에 양의 DragW를 요구하면 오류로 거부한다.
- 자화 전류와 단자 전류의 **별도 원형 한계**를 적용한다.
- 전압은 비선형 자속맵을 직접 사용한다. 과거 Ld/Lq/PM 조합과 저항 누락식은 제거했다.
- `calcTotalElecLossFromInterP`의 기존 Hys/Eddy 정규화는 바꾸지 않았다. 속도 단위만
  바로잡았으며 새 실제 맵 회귀는 해당 미감사 정규화를 사용하지 않는다.

## API 변경과 이전 예제

`EECLUTdq` 생성자의 열 번째 인자 `LossContract`가 필요하다. 이전 9인자 호출은
`MotorControl:MissingLossContract`를 낸다. 기존 손실 합계를 임의로 한쪽에 귀속하지 않는다.

```matlab
% diagnostic allocation only; choose the physical law from independent evidence
contract = struct('Name','explicit diagnostic', ...
    'PowerFcn',@(d_pk,q_pk) struct('InputW',40,'DragW',10), ...
    'RdcOhm',0.1,'MaxMagnetizingRMS',200,'MaxTerminalRMS',200);
obj = EECLUTdq(fd,fq,ld,lq,pm,legacyLoss,omegaE,speed,poles,contract);
```

`MainComp_MTPA.m`의 15,000 rpm·438.2 N·m 원 모터/표/`MachineData`와 전압 규약은
확인되지 않았다. 이 예제는 활성 Motor-CAD를 읽기 전에 명확한 오류로 중단한다.
현재 e10로 원 사례를 바꾸지 않았다. 새로운 원본 입력이 있으면 이름·해시·전압·귀속을
고정한 뒤 재현한다. 맵 영역은 제공된 보간기가 책임지며 이번 고정 맵 보간은 영역 밖
외삽을 금지했다. 범용 불규칙 맵의 유효영역을 자동 추정하는 기능은 아니다.
